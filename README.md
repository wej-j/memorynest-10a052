# Remory

 **Remember. Relive. Remory.**

Remory is an AI-powered memory app that helps people capture meaningful moments quickly, enrich them later, and find them again when they matter.

## Why Remory?

We often experience moments we want to remember, but while they are happening, we usually do not have the time to document everything properly. Later, important details are already forgotten.

Remory is built around one simple idea:

**Capture now. Complete later.**

A memory can start with only a photo, a few keywords, a voice note, a location, or a short text. Nothing is mandatory, and everything can be edited afterwards.

## What Remory Does

Users create a **Moment** and decide what they want to add:

- Photos
- Keywords
- Longer text
- Date and time
- Location
- Ratings
- Tags

Remory then helps turn these fragments into a richer, more meaningful memory.

For example, instead of writing a full diary entry, a user could simply save:
*Hackathon, Hamburg, AI, pizza, team*

Together with a photo, date, and location, AI can use this context to generate a natural description and help structure the memory.

## Our Three Principles

### Capture
Saving a memory should take only a few seconds.

### Rediscover
Moments should be easy to find again through search, dates, places, tags, and content.

### Reduce Effort
The app should do as much work as possible for the user instead of creating more work.

## AI Support

Remory can use AI to:

- turn keywords into natural text
- use photos, text, date, and location as context
- suggest tags
- enrich a moment with additional information
- help structure incomplete memories
- make memories easier to search and rediscover

The user stays in control: AI-generated content can always be changed.

## Hackathon Prototype

Our current prototype focuses on the core Remory experience:

1. Open the app
2. Create a new Moment
3. Add as much or as little information as you want
4. Let AI help enrich the memory
5. Save it
6. Browse and search saved Moments later

The goal of the prototype is not to build every planned feature, but to demonstrate how effortless memory capture can become.

## Current Features

- Create and save Moments
- Add text and keywords
- Add photos
- Store date and time
- Store or edit location information
- Browse saved Moments
- Search existing Moments
- AI-assisted memory creation and enrichment
- Edit information afterwards

## Future Vision

Remory can grow into a personal memory companion that understands how individual moments belong together.

Future features could include:

- automatically grouping Moments into trips or events
- natural-language search such as  
  *“Show me my favorite moments from Italy.”*
- map-based memory discovery
- automatic tags and categories
- information about places, restaurants, landmarks, and activities
- trip and event summaries
- personal retrospectives
- smarter connections between related memories
- sharing and exporting memories

## Technology

The prototype is built with:

- **Bilt** – AI-assisted app development
- **React Native**
- **Expo**
- **TypeScript**
- **Expo Router** – navigation
- **AsyncStorage** – local data persistence
- **AI / LLM integration** – memory generation and enrichment
